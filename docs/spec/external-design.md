## 2. 画面遷移
```
[初回]
SCR-01 ようこそ → (サインイン) → SCR-02 年齢 → SCR-03 ジャンル
   → SCR-04 ホーム(株が0件:「最初の株を追加」)
   → SCR-05 株を追加 → SCR-06 カメラ → 撮影後の比較
   → SCR-10 通知の許可(最初の撮影のあと1回だけ) → SCR-04 ホーム

[ふだん]
SCR-04 ホーム ─ 株をタップ ────→ SCR-08 株の詳細 ─ 記録ボタン(その場で記録)
              ├ 株を長押し ────→ 「水をやった」(FN-14)
              ├ (後回し)「巡回する」 ─→ SCR-07 巡回モード ─ 各株で SCR-06 カメラ → 次の株 → 完了
              ├ 「株を追加」 ──→ SCR-05
              └ 設定 ──────────→ SCR-11 設定 ─ SCR-12 アカウント削除

SCR-08 株の詳細 ─ 撮影 → SCR-06 カメラ
                ├ 編集 → SCR-05
                ├ 共有設定 → SCR-09
                ├ 写真をダウンロード → SCR-13(この株を選んだ状態で開く)
                └ 削除(確認あり) → SCR-04 ホーム

SCR-11 設定 ─ 写真をダウンロード → SCR-13
SCR-12 アカウント削除 ─ 「先に写真をダウンロード」 → SCR-13(戻ると SCR-12 に戻る)
```
- 巡回モード(SCR-07)は後回しのため、ステップ1では「巡回する」ボタンを出さない。撮影通知をオンにした人は、通知からホーム(SCR-04)を開く(株を選んで撮影する。通知から直接カメラを開くかは、巡回モードを戻すときに決める)。
- 戻る操作は、どの画面でも1つ前の画面に戻る。入力途中で戻ると、内容が消えることを確認する。

## 3. 画面ごとの設計

### 3.1 共通のルール
- 表示は日本語。日付の選択なども日本語(実装済み。`test/features/home/home_screen_test.dart`)。
- エラーは、原因が分かる文で、その項目のそばに出す(例:「名前は50文字以内で入力してください」)。通信や保存の失敗は「もう一度試してください」と、やり直せる形で出す。
- 公開に関わる操作には、必ず「誰に何が見えるか」を表示する(REQ-029)。
- 根底は「交流と交換」(`requirements.md` 0章)。記録は、交流と交換を効果的に実現するためのもの。記録の画面は、記録すること自体を目的にせず、見せ合える・交換できることに役立つ形にする。文言は「記録しましょう」ではなく、見せる・交換する価値を伝える。
- 撮影から保存までの間に、広告は出さない(REQ-021)。
- 読み込み中は進行中の表示、データがないときは案内と次の操作を出す。

### 3.2 SCR-01 ようこそ
```
RootLog
記録と来歴を残すアプリです。
はじめは、すべて非公開です。
[Apple でサインイン]
[Google でサインイン]
```
- 入力:なし。出力:サインイン後に SCR-02(初めての人)またはホーム(登録済みの人)へ。
- エラー:サインインを取り消した場合は、そのままこの画面。失敗した場合は「サインインできませんでした。もう一度試してください」。
- 権限:ログイン前の画面。

### 3.3 SCR-02 年齢の確認
```
年齢を選んでください
( ) 13〜17歳
( ) 18歳以上
※ 後から変更できません。売買・交換は18歳以上の方だけです。
13歳未満の方は利用できません。
[次へ]
```
- 入力:13〜17歳/18歳以上(どちらかを必ず選ぶ)。13歳未満の場合は、利用できない旨を案内して終了する。
- 出力:年齢区分(`13-17` / `18+`)を保存。保存後、SCR-03へ。
- 権限:年齢区分はアプリから変更できない(REQ-037)。

### 3.5 SCR-04 ホーム(植物リスト)
```
RootLog                                   [設定]
── 窓辺 ──
 モンステラ  観葉植物全般・デリシオーサ      [最新写真]
   前回の撮影から 8日   [来歴]   [復活チャレンジ]
── ベランダ ──
 アガベ ○○   アガベ
   前回の撮影から 3日
── 置き場所未設定 ──
 ...
                                [+ 株を追加]
```
- 株が0件のとき:「まだ株がありません」の案内と「最初の株を追加」だけを出す(右下のボタンは出さない)。
- 並び:置き場所は名前順、未設定は最後。置き場所の中は追加した順(古いものが上)。
- 操作:株をタップで SCR-08(実装済み。#65。編集は詳細の「編集」から)、株を長押しで「水をやった」(FN-14)、右下の「株を追加」で SCR-05、設定で SCR-11。
- 出力:各株の名前・ジャンル(複数のときは「・」でつなげる)・品種・タグ・健康状態(「初期」以外のとき「健康状態:不調」)・前回の水やり(記録があるとき「水やり:3日前」)・(最新写真・前回の撮影からの日数・来歴の印)。
- エラー:読み込めないときは「株を読み込めませんでした」。
- 現状:名前・ジャンル・品種・タグ・置き場所のまとめ・0件の案内・「株を追加」まで実装済み。加えて(#68):株を**長押し**して水やりを記録(「『モンステラ』に水やりを記録しました」「取り消し」)、前回の水やりからの日数(「水やり:今日 / 1日前 / 3日前」。暦の日付の差で、出来事の日時で数える。記録がなければ出さない)、健康状態(「初期」以外のとき)。最新写真、前回の撮影からの日数、来歴の印、設定への入口は未(「巡回する」は後回し)。
- 権限:自分の株だけ(他人の株は見えない。REQ-035)。

### 3.6 SCR-05 株を追加・編集
```
株を追加                                    [保存]
名前 *            [                    ]  (50文字まで)
ジャンル *        (1〜3個。実生はタグで選びます)
                  [x] 観葉植物全般(パキラ・ゴムの木・ガジュマル・サンスベリア等)
                  [ ] 塊根  [ ] アガベ  [ ] 多肉/サボテン  [ ] ビカクシダ
                  [ ] アロイド(モンステラ・ポトス・アンスリウム・アロカシア等)  [ ] 珍奇植物  [ ] その他
品種              [                    ]  (80文字まで)
入手日            [ 年 / 月 / 日 ]         (今日以前)
入手先            [                    ]  (100文字まで。非公開です)
置き場所          [                    ]  (30文字まで。名前だけ。住所は入れないでください)
鉢の号数          [      ]                 (10文字まで)
購入価格          [          ] 円            (任意。自分だけが見られます。非公開です)
タグ              [ ] 復活チャレンジ   [ ] 実生
```
- 入力条件は、権限ルールと同じ(`internal-design.md` 5章)。名前は必須。前後の空白は取り除き、空欄は「未設定」にする。
- エラーの文言:「名前を入力してください」「名前は50文字以内で入力してください」「品種は80文字以内で入力してください」「入手先は100文字以内で入力してください」「置き場所は30文字以内で入力してください」「鉢の号数は10文字以内で入力してください」「入手日は今日以前の日付を選んでください」。複数あるときはまとめて出す。
- ジャンル:傾向の整理に使う。複数選択(1〜3個)。0個・4個以上はエラー:「ジャンルを1つ以上選んでください」「ジャンルは3つまで選べます」。**実生は、ジャンルではなくタグ「実生」で表す**(傾向を数えるときに、実生タグの株を「実生」として数える)。初期は「観葉植物全般」を選択済み。
- 購入価格:任意。0以上の整数(円)で、99,999,999円まで。空欄は「未設定」。エラーの文言:「購入価格は0以上の整数で入力してください」「購入価格は99,999,999円以下で入力してください」。画面に「購入価格は自分だけが見られます」と表示する。公開用データには出さない(内部設計 3.5)。
- 出力:追加のとき、株を初期公開(範囲は写真のみ)で作成し、保存後すぐ SCR-06(最初の撮影)へ。編集のとき、共有設定と作成日時は変えずに更新し、元の画面へ戻る。
- 削除(編集の場合のみ):確認のあと削除し、ホームへ戻る。写真・記録もあわせて消えることを説明する。
- 権限:自分の株だけ作成・編集・削除できる。
- 現状:追加の入力画面は実装済み(#17)。画面の上部に、初期公開(写真のみ。公開の説明を確認したあとから他の人に見える。株ごとにいつでも非公開にできる。入手先・置き場所・購入価格は公開されない)を表示する。保存後は、ホームに戻って「追加しました」と出る。保存後の撮影画面(SCR-06)への遷移は未。置き場所は、すでに使った置き場所を候補として選べる。戻るときに入力があれば「入力を破棄しますか?」と確認する。購入価格は、カンマ・全角の数字も受け付ける。データ・入力検証・保存(メモリ)は実装済み。
- 編集モード(#62):株の詳細(SCR-08)の「編集」から開く(#65。#62 では、詳細ができるまでの暫定で、ホームの株のタップから開いていた)。画面のタイトルは「株を編集」。入力欄には今の値が入り、追加のときの公開の説明は出さない。保存すると、共有設定・作成日時・健康状態は変えずに更新し、詳細に戻って「更新しました」と出る。変えて戻るときは、追加と同じく「入力を破棄しますか?」と確認する(開いたときから変えていなければ、確認しない)。更新しようとした株がすでにないときは、「株が見つかりません」と出て、詳細も閉じてホームに戻る。
- 削除(#62、編集モードの下部の「この株を削除」):「株を削除しますか?」「写真・記録もあわせて消えます。元に戻せません。」と確認し、「削除する」で詳細も閉じてホームに戻り、「削除しました」と出る。「やめる」なら編集画面に残る。

### 3.7 SCR-06 カメラ
```
  (カメラ画面。※ゴースト表示(前回の写真を半透明で重ねる)は後回し)
[端末の写真から選ぶ]              (◎)撮影
────撮影後────
今回 | 1週間前 | 1か月前   (並べて比較)
[保存して次へ]   [撮り直す]
```
- 入力:アプリ内カメラでの撮影(撮影元 `camera`)、または端末の写真の選択(撮影元 `gallery`)。
- 端末の写真を選んだときは「端末の写真は、来歴になりません」と表示する。
- 出力:すぐにアップロードする。サーバーが来歴かどうかを判定し、結果を表示する(3.7.1)。
- エラー:アップロードに失敗したら「写真を送れませんでした。もう一度試してください」(端末に残して再試行できる形は内部設計 8章)。カメラの許可がないときは、許可が必要な理由と設定への案内。
- 権限:自分の株にだけ写真を追加できる。元画像は誰も読めず、処理後すぐ削除される(REQ-016)。

#### 3.7.1 来歴の表示(SCR-04・SCR-08 でも同じ文言)
| サーバーの判定(`provenanceReason`) | 表示 |
|---|---|
| 処理中 | 「確認中」 |
| `ok`(来歴つき) | 印と「この日時までに撮影された写真」(受信時刻) |
| `gallery` | 「端末の写真のため、来歴になりません」 |
| `no_capture_time` | 「撮影時刻が読み取れないため、来歴になりません」 |
| `capture_time_mismatch` | 「撮影時刻と受信時刻が離れているため、来歴になりません」 |
| `duplicate` | 「同じ写真が登録済みのため、来歴になりません」 |
- 「この日時までに」と書くのは、端末側の情報は偽装できうるため。確実に保証できるのは、サーバーが受信した時刻だけ(設計0 1.4 の限界)。

### 3.8 SCR-07 巡回モード(後回し:2026-09-26 決定。ステップ1では作らない。設計は残す)
```
巡回モード  窓辺  2 / 5
  モンステラ
  (前回の写真)
[撮影する]   [水をやった]   [スキップ]
────完了────
今週の変化: 5株を撮影、4株に水やり
[ホームへ]
```
- 動き:置き場所の順に、株を1つずつ表示 → 撮影(SCR-06)→ 「水をやった」を1タップ → 次の株へ。最後に完了画面。撮影も水やりも、株ごとに省略できる。
- 出力:撮影した写真、水やりの記録。完了画面で、撮影した株の数と水やりの数を出す。
- 途中で抜けても、そこまでの記録は残る。
- 権限:自分の株だけ。

### 3.9 SCR-08 株の詳細(栽培ストーリー)
```
モンステラ   観葉植物全般・デリシオーサ        [編集] [共有設定]
窓辺・5号鉢・入手日 2026/05/01
健康状態:不調(2026/09/20〜)
[撮影]  [水をやった]  [植え替え] [肥料] [剪定] [メモ] [段階 ▼] [健康状態 ▼]
── 2026/09/20 ──
  写真 [来歴]   この日時までに撮影された写真 09/20 10:03
  水やり
── 2026/09/13 ──
  段階:新芽   メモ:新しい葉が出た
  健康状態:要観察 → 不調   メモ:葉がしおれてきた
[写真をダウンロード]
```
- 表示:写真と記録の時系列(新しいものが上)。来歴つきの写真に印。削除された写真がある場合は「削除された写真があります」を表示する(REQ-019)。
- 記録ボタン:水やり・植え替え・肥料・剪定・メモ・段階(入手・発根・新芽・植え替え・開花・株分け・復活・枯死)。メモは500文字まで。記録の日時は、今日以前(未来の日時は選べない)。
- 健康状態:「健康状態 ▼」で、いまの状態(初期・元気・要観察・不調・復活中)を1タップで変えられる(REQ-048、FN-27)。変えるたびに記録として残り、時系列に「健康状態:○○ → ○○」と出る(メモを添えられる。任意、500文字まで)。「初期」は、登録直後で、まだ状態を決めていない状態(名前は仮。要件 Q13)。段階(入手・発根など)は節目の記録、健康状態は「いまの状態」で、別のもの。「不調」にした株から相談・レスキュー株へ進める導線は、後のステップで作る。
- 記録の編集・削除:メモと日時は後から直せる。種類は変えられない(記録の時刻はサーバー時刻で固定。REQ-023)。
- 写真:タップで拡大し、削除(確認あり)。
- ダウンロード:「写真をダウンロード」で SCR-13 を開く(この株を選んだ状態)。タイムラプスや動画を自分で作るための素材(REQ-046)。タイムラプス再生(FN-16)は後回し。
- エラー:記録できなかったときは「記録できませんでした。もう一度試してください」。
- 前回の水やり(#68):健康状態の下に「前回の水やり:3日前(2026/09/23)」(水やりの記録があるとき)。
- 現状(#65):株の詳細を実装済み。AppBar に株の名前と「編集」。本文に、ジャンル・品種、置き場所・鉢の号数・入手日、健康状態(「初期」以外のとき「健康状態:不調(2026/09/20〜)」。日付は最後に変えた記録の日)。ボタン:「水をやった」(1タップ。日時は今。「水やりを記録しました」と出る)、植え替え・肥料・剪定・メモ(日時とメモを入れるダイアログ)、「段階 ▼」(8つのメニュー → ダイアログ)、「健康状態 ▼」(5つのメニュー。いまの状態は選べない → メモ・日時のダイアログ)。ダイアログの日時は「今」が初期で、「日付を選ぶ」で今日までの日付を選べる(今日を選ぶと今、過去の日を選ぶとその日の12時)。メモは500文字まで。メモの記録は、メモが必須。エラーはダイアログの中に出て、直すまで閉じない。時系列は、日付ごとにまとまり、新しい日が上(見出し「── 2026/09/20 ──」)。各行は「水やり」「段階:新芽」「健康状態:初期 → 不調」など、メモがあれば下に出る。0件のときは「まだ記録がありません。上のボタンから記録できます。」。行をタップすると、メモと日時を直せる(種類は変えられない)。「この記録を削除」は確認のあと削除する。写真・撮影・共有設定・ダウンロードのボタンは、それぞれの機能ができるときに足す。
- 権限:自分の株だけ。

### 3.10 SCR-09 共有設定(株ごと)
```
共有設定  モンステラ
公開する範囲を選びます。
( ) 非公開(自分だけ)
( ) 公開  範囲: (写真のみ / 履歴まで / 入手先まで)
────────
初期は、写真だけが公開されます(公開の説明を確認したあとから他の人に見えます)。
公開すると、交換・売買・レスキューのときに、相手があなたの記録を見て安心できます。
他の SNS で引用して見せることもできます。
※ 公開はステップ3から使えるようになります。今は設定だけ保存されます。
```
- 入力:公開/非公開、範囲(写真のみ/履歴まで/入手先まで)。初期は公開・写真のみ(2026-09-26。オプトアウト)。
- 出力:設定を保存する。公開を選んだ場合は、その範囲で「誰に何が見えるか」を説明する(例:「履歴まで:写真と水やり・植え替えの記録が、ログインしている人に見えます。入手先は見えません」)。
- ステップ1では、公開を選んでも他の人が見る画面がない。保存だけして「公開はステップ3から使えます」と表示する。
- 権限:自分の株だけ。公開用データの書き出しはサーバーだけが行う。
- 現状(#70):実装済み。株の詳細の「共有設定」から開く(詳細に「共有:公開(写真のみ)」「共有:非公開」も出る)。「非公開(自分だけ)/公開」と、公開の範囲(写真のみ/履歴まで/入手先まで。非公開のときは選べない)を選ぶ。選ぶたびに、「この設定で、誰に何が見えるか」が変わる。
  - 非公開:自分だけが見られる。他の人には見えない。
  - 写真のみ:名前・ジャンル・品種・タグと、写真が、ログインしている人に見える。
  - 履歴まで:上に加えて、記録の種類と日付(水やり・植え替え・段階など)が見える。メモの中身は見えない。
  - 入手先まで:上に加えて、入手先が見える。
  - 公開のときは、「置き場所・鉢の号数・購入価格・健康状態・メモの中身は、どの範囲でも見えません。」も出す。
  - この説明は、サーバーが実際に書き出す項目(`publicPlant.ts`)と食い違わないよう、テストで固定している。
  - 「保存」で保存し、詳細に戻って「共有設定を保存しました」と出る。変えて戻るときは「入力を破棄しますか?」と確認する。株がすでにないときは、「株が見つかりません」と出て閉じる(詳細も閉じてホームに戻る)。
  - 初回の公開の説明の確認(REQ-049。SCR-01)は未。確認するまで、サーバーは公開用データを書き出さない(#58)。

### 3.11 SCR-10 通知の許可

来週また撮る日を、通知でお知らせしますか?

### 3.13 SCR-12 アカウント削除
```
アカウントを削除します
次のものがすべて消え、元に戻せません。
・登録した株、記録、写真
・公開している内容
・ログイン情報
・記録した写真は、削除するとダウンロードできません。
  [先に写真をダウンロード]
[削除する]   [やめる]
```
- 動き:説明 → (希望すれば SCR-13 で写真をダウンロード)→ 確認(もう一度「削除する」を押す)→ 削除 → ようこそ画面へ。
- エラー:削除できなかったら「削除できませんでした。もう一度試してください」。何が削除されたか分からない状態にならないよう、サーバーがまとめて処理する(FN-23)。
- 権限:本人だけ。

### 3.14 SCR-13 写真をダウンロード
```
写真をダウンロード
期間     [ 2026/05/01 ] 〜 [ 2026/09/26 ]     (初期:すべての期間)
株       [x] すべて   [ ] 株を選ぶ ▼
           [x] モンステラ  [x] アガベ ○○ ...
写真     42枚が対象   [写真を選ぶ]            (一覧で、1枚ずつ外せる)
保存先   この端末の写真フォルダ
[写真フォルダに保存する]
```
- 入力:期間(受信時刻の日付で数える)、株(複数選択)、写真(対象の一覧から1枚ずつ外せる)。初期は、全期間・全株・全写真。
- 動き:「写真フォルダに保存する」で、対象の写真を受信時刻の古い順に1枚ずつ保存する。進み具合(「12 / 42枚」)と、途中でやめるボタンを出す。やめても、保存済みの写真は残る。
- ファイル名:`株の名前_連番_受信日時.jpg`。連番は株ごとに受信時刻の順。名前に使えない文字は置き換える。
- 出力:画像だけ(水やり・メモなどの記録は出さない)。来歴の印は付けない。位置情報は入っていない(サーバーで削除済み。REQ-016)。無料プランの画像は長辺1600px程度。
- 対象にならないもの:削除した写真、処理中の写真(確認中のもの)。
- 前回のダウンロード済みの写真は判別しない(同じ範囲をもう一度保存すると、もう一つ保存される)。
- エラー:読み込めなかったとき「写真を読み込めませんでした。もう一度試してください」。保存できなかったとき「保存できませんでした。写真フォルダへの保存を許可してください」(許可の案内)。対象が0枚のとき「対象の写真がありません」。
- 権限:自分の写真だけ(REQ-035)。写真フォルダへの保存の許可は、初めて保存するときに案内する。

## 5. 権限(誰に何が見えるか)
ステップ1では、すべて本人だけが見られる。公開用のデータ(`publicPlants`・`publicProfiles`・`public/`)は、ステップ3まで、アプリからは参照しない。

| データ | 本人 | 他の人(ログイン済み) | ログインしていない人 | 書き込める人 |
|---|---|---|---|---|
| ユーザー情報(表示名・年齢区分・ジャンル・都道府県・通知設定) | 読める | 読めない | 読めない | 本人(年齢区分・課金状態は不可) |
| 株(入手先・購入価格・健康状態を含む。購入価格は公開用データに出さない) | 読める | 読めない | 読めない | 本人(来歴の印は不可) |
| 記録(水やり等) | 読める | 読めない | 読めない | 本人(記録時刻はサーバー時刻) |
| 写真の記録(`photos`) | 読める | 読めない | 読めない | サーバーだけ |
| サーバーが残す記録(`systemLogs`) | 読める | 読めない | 読めない | サーバーだけ |
| 元画像(`uploads/`) | 読めない | 読めない | 読めない | 本人が作成のみ(撮影元・株の指定が必須) |
| 処理済みの写真(`photos/`。ダウンロード(FN-26)もこの範囲) | 読める | 読めない | 読めない | サーバーだけ |
| 公開用データ(`publicPlants`・`public/`) | 読める | 読める | 読めない | サーバーだけ |
| 写真の重複検出用(`photoHashes`) | 読めない | 読めない | 読めない | サーバーだけ |

- 公開を選んだ株の公開用データは、選んだ範囲(写真のみ/履歴まで/入手先まで)だけをサーバーが書き出す。非公開に戻したら、公開用データと写真のコピーを削除する。
- 権限は、画面で隠すだけでなく、サーバー(権限ルール・Cloud Functions)で強制する(REQ-035)。確かめるテストは `test-plan.md` 8章。
