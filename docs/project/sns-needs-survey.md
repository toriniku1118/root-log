# 植物アプリ SNSのニーズ調査と収益化の見込み(2026-09-25)

## 調査方法と限界
- X・Instagram・Threadsの投稿を、Web検索(site:指定)で拾える範囲で確認。各SNSの本体ページは直接読み込めず(robots.txtで拒否)、ブラウザ拡張も未接続だったため、投稿の本文は検索結果に表示された範囲のみ。
- そのため「投稿の量(件数)」は測れていない。ここでの判断は「そういう声・動きが存在するか」の定性的な確認にとどまる。
- 補助として、ニュース、調査(第一園芸)、アプリストア、Q&Aサイトを参照。

## 機能ごとのニーズと収益への効き方
| 機能 | ニーズの証拠 | 強さ | 収益につながるか |
|---|---|---|---|
| 成長記録・タイムラプス | Instagramで「#成長記録」付きの投稿がある(例:グラキリスの発芽)。ガーデニングQ&Aで「記録を一括管理できるアプリを探している」質問に11件の回答(アプリ5・手書き3・SNS2等でバラバラ) | 中 | 弱い。個人開発の記録アプリは多数あり、評価数は数十件程度(成長記録カメラ:評価17件・有料300円、草木帖:評価28件・有料800円)。記録単体では人が集まりにくく、課金も数百円の買い切りが相場 |
| 資材の余り(土) | 土の捨て方は社会問題として報道(日テレNEWS:東京23区は土をごみに出せない、公園への不法投棄)。Xでも処分方法が分からないという投稿や、ホームセンター(コメリ等)の回収の話題 | 強 | 弱い。困りごとは強いが、解決策は「回収」であり、中古の土を欲しがる人は少ない。ホームセンターの回収サービスも広がっている |
| 資材の余り(鉢) | 「空き鉢がたまる」といった投稿は検索では見つからず。コーナンでは陶器鉢が600〜700円で話題 | 弱〜中 | 弱い。新品が安いため、交換の価値が出るのはデザイン鉢・大型鉢に限られる(未検証のまま) |
| 挿し木・株の交換 | オフラインの交換会は存在(みんなの趣味の園芸の交換イベント一覧、自治体の草花交換会、県の種苗交換会)。若手のSNS上での交換募集は検索では確認できず | 中(中高年寄り) | 中。交換は無料なので手数料にならない。人が集まれば広告・出品オプションの土台 |
| レア植物の入荷情報 | 専門店が入荷情報をX・Instagramで発信するのが一般的。ホームセンター(カインズ、コーナン)でも珍奇植物・塊根植物を扱い、「塊根植物で話題のコーナン」といった投稿がある | 強 | 強い(毎日開く理由→広告、店舗の有料掲載)。ただしアガベは組織培養で価格が数百円まで下落し、品種によって「取り逃したくない」度合いに差 |
| イベント | 開催が多く盛況(ボタニカル夜市 120店舗以上、草乱祭 出店者100以上、オキボタ等)。NHK出版の趣味の園芸公式もイベントを告知。情報は主催者ごとのアカウントに分散 | 強 | 中。まとめて探せる価値はある。主催者はXで無料告知できるため、有料掲載にお金を払うかは未確認 |
| 相談 | Threadsでは「水切れからの回復法」など、困りごとへの解説投稿が多い。知恵袋の観葉植物カテゴリは1日約10〜15件の質問 | 強 | 中。広告の表示機会とWeb公開による検索集客。課金には直結しにくい |

## 対象ユーザーについての発見
- 第一園芸の調査(2023年、5,000人):Z世代の約半数は観葉植物を育て始めて1〜2年。選ぶ基準は「育てやすさ」が83%で最多。→「始めたばかりの若手」は確かに存在する。
- ただし、最も収益につながる入荷情報・イベントに熱心なのは、塊根・アガベ・珍奇植物などにハマった「収集寄り」の層。始めたばかりの若手とは関心がずれる。
- 育てるうちに約6割が「植物が好きになった」(同調査)ことから、「始めたばかり → ハマる → 収集」という流れで両方の層をつなぐ設計が考えられる。

## 収益化の見込み(SNS調査を踏まえた評価)
- ニーズがあるもの:入荷情報、イベント、相談、記録。いずれも声・動きは確認できた。
- 課金まで届きそうなもの:入荷情報(広告・店舗掲載・通知の有料枠)が最有力。イベントは集客の入口として有効。
- 困りごとは強いが収益になりにくいもの:土の処分、鉢の余り。当初の出発点だった「資材の回し合い」は、収益の柱にはなりにくい。
- 記録:必要とされているが、競合が多く課金は弱い。「毎日開く習慣」と「取引・相談の信頼材料」の役割に徹する。
- 年20万円の確率は従来の見立て(1年以内5〜10%)から大きくは変わらない。上げる余地があるのは入荷情報とイベントを早めに出す場合。

## 設計への示唆(検討事項)
1. 入荷情報とイベントの優先度を上げる(フェーズ2a → フェーズ1.5前後に前倒しを検討)。
2. 対象を「始めたばかりの若手」+「ハマり始めた層(塊根・アガベ・ビカクシダ等)」に広げ、入口と収益の役割を分ける。
3. 資材の交換は「差別化の脇役」に位置づけ直す(大型鉢・デザイン鉢・挿し木に絞る)。
4. SNSでの直接確認は未完了。X・Instagram・Threadsで「入荷」「交換」「鉢 余り」の投稿量と反応を、ログインした状態で数える作業が残っている。
