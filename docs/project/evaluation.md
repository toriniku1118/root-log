# 植物アプリ 総合評価(2026-09-25)

対象:「植物アプリ_コンセプト」の現時点の内容(観葉植物×始めたばかりの若手/交換・売買+シンプルな成長記録+イベント管理/収益は広告が第一)。
問い:①年20万円の利益は達成可能か ②将来のスケールは現実的か。

## 結論
- 年20万円:1年以内は5〜10%、検証がうまくいった前提で2〜3年なら20〜30%(いずれも推測)。不可能ではないが、必要な利用者規模に対して「集客」と「運営の手間」が最大の壁。
- スケール:植物市場そのものの天井は高い(GreenSnapが月間1,100万人規模)。ただし週3〜7時間の副業のままで数万人規模を超えるのは非現実的。大きくするなら「検証で手応えが出た時点で、関わり方(時間・資金・仲間)を変える」判断が必要。
- 最大の競合はPlantaではなくGreenSnap(国内・コミュニティ・自社イベント・EC・法人事業を既に持つ)。交換機能を足されると差が縮まる。

## 1. 収益の逆算
### 費用
- Apple Developer Program 年$99(約1.5万円、為替による)、Google Play 初回$25。サーバーはFirebase無料枠から開始。
- 年20万円の利益には売上 約22〜23万円が必要。
- 税務:会社員の副業所得が年20万円を超えると確定申告が必要(20万円以下でも住民税の申告は必要)。

### 必要な利用者規模(組み合わせ例:広告10万円+出品オプション4万円+プレミアム4万円+送客等2万円)
- 広告10万円:日本の個人開発アプリのeCPM約30〜80円(教育系の例)。50円・1人1日5表示なら、毎日使う人(DAU)約1,100人。
- DAUが月間利用者の2〜3割と仮定 → 月間利用者 約4,000〜5,500人。
- アプリの30日後の継続率はライフスタイル系で約9%(Adjust、2022年、世界の中央値)。長く残るのが数%とすると、累計で数万〜10万ダウンロード規模が必要(推測)。
- 出品オプション4万円:1回200円なら年200件(月17件)。月間出品が数百件あれば1割弱の購入で届く。
- プレミアム4万円:月300円・Apple手数料15%後で約13人(年間継続)。
- → 個人開発で「数万ダウンロード」は十分に前例があるが、広告費ゼロ・週3〜7時間では1年目に届くのは難しい規模。

### 参考:比較対象
- 個人開発の実例:アプリ10本で月約3万円(年約36万円)。初収益まで約半年、最初の数か月はダウンロード数十件。
- ジモティー:売上の約8割が広告、約2割が出品の有料オプション・送客。2026年12月期予想 売上高21.35億円・営業利益5.49億円。→ 「広告+出品オプション」の構造自体は実証済み。

## 3. 主なリスクと対策
1. 集客が立ち上がらない(最大のリスク)→ プロトタイプを自分とテスターで運用し、5か月目の判定点で確認。タイムラプス動画のSNS拡散、イベント会場での声かけ、植物店との連携。
2. 機能が多すぎて完成しない → フェーズ1は「記録+イベント」だけ(遅れる場合は記録と撮影だけに削る)。交換は8か月目の判定点(公開率・「交換したい」という声)で需要を確認してから。
3. 運営負荷でやめてしまう → 通報・ブロック・禁止ワードを最初から。イベント情報は主催者登録を早めに。
4. GreenSnapに交換機能を足される → 「若手・日本の号数規格・イベント会場での受け渡し」に特化して先行。
5. 広告単価が低い → 出品オプションとリワード広告(見ると上位表示が無料)を早めに試す。

## 4. スケールの見立て
| 段階 | 月間利用者 | 年間売上の目安(推測) | 必要な関わり方 |
|---|---|---|---|
| 副業の目標 | 約4,000〜6,000人 | 約20〜25万円 | 週3〜7時間+検証 |
| 副業の上限付近 | 約3万人 | 約50〜100万円 | 週10時間以上、運営の一部自動化・外部協力 |
| 事業化 | 数十万人〜 | 数千万円〜 | 専業・チーム・資金。法人向け(イベント・植物店・ブランド)収益が主軸に |
- 3万人の試算:DAU 2割=6,000人×1日5表示×eCPM50円×365日 ≒ 広告 約55万円+オプション等。
- 横展開の可能性:「趣味の資材の回し合い+記録+イベント」はアクアリウム・爬虫類・盆栽などにも同じ型で広げられる。規模を狙うならこの方向。
- 天井は高いが、上の段に進むほど副業の枠(時間・初期費用ゼロ)を超える。

## 5. 判断基準(やめる/進める)(2026-09-25 更新)
前提:LINEオープンチャット等の手作業の実験は行わない(ユーザー決定)。アプリのプロトタイプを作り、自分で運用しながら判断する。開発順は「植物アプリ_コンセプト」の開発ステップ(0 準備 → 1 記録と来歴 → 2 入荷情報とイベント → 3 記録を見せ合う → 4 有料プラン → 5 売買・交換 → 6 拡大)。対象はハマっている層。数値はすべて仮の目安で、実績を見て調整する。
- 判定は3段階:進める(目安を満たす)/見直す(改善してから2か月後に再判定)/やめる・方針転換(同じ判定点で2回続けて「見直す」以下、または「やめる」の条件に当たる)。
- 「やめる・方針転換」の選択肢:開発の停止、または運営の手間が小さい形(成長記録と撮影だけのアプリ+広告)に縮小して続ける。

### 判定点(2026-09-25 更新:開発ステップの再構築に合わせて時期を調整)
| 時期(目安) | 段階 | 進める目安 | 見直す | やめる・方針転換 |
|---|---|---|---|---|
| 4か月目 | ステップ1(記録と来歴)を自分とテスター(ハマっている人5〜10人)で運用 | 自分が続けている。テスターの半数以上が4週後も週1回以上撮影。テスターが来歴記録を「取引で見せたい」と答える。セキュリティのフェーズ1必須項目をすべて満たす | テスターの継続が2〜5割 | 自分自身が続かない、またはテスターの継続が2割未満 → 記録・来歴の設計を見直す |
| 8か月目 | ステップ2(入荷情報とイベント)、ストア公開から約2か月 | 累計ダウンロード300件以上。30日後も使う人10%以上。入荷情報の投稿が関東・関西で週10件以上。売り切れ・誤情報の報告が2割以下。広告費ゼロの流入経路が1つ以上 | ダウンロード100〜300件、30日後の継続5〜10%、入荷情報の投稿が週3〜10件 | ダウンロード100件未満かつ30日後の継続5%未満 → 集客の経路を変えて2か月後に再判定。再度未達なら方針転換 |
| 11か月目 | ステップ3(記録を見せ合う) | 月間利用者1,000人以上。記録の公開率30%以上 | 公開率15〜30% → 公開したくなる動機を見直す | 公開率15%未満 → 「記録公開を取引の条件にする」前提を見直す |
| 12か月目 | ステップ4(有料プラン)+収益の確認+専業に切り替えるかの判断 | 有料プランの加入率3%以上。専業の判断は「植物アプリ_市場規模と収益見通し」6章の基準をすべて満たす場合のみ(1年目の売上は基本シナリオで約6万円のため、12か月目に年20万円は目標にしない) | 加入率1〜3%、または月間利用者が毎月5%以上伸びているが専業基準に届かない → 副業のまま1年延長 | 月間利用者500人未満で伸びが止まっている → 縮小または停止 |
| 18か月目 | ステップ5(売買・交換) | 月間出品100件以上。成立率3割以上。出品オプションの購入が発生。トラブルの通報が取引100件あたり1件未満。年20万円の利益ペース(月の売上約2万円) | 出品30〜100件 → 利用条件・出品の手間を見直す | 出品30件未満が続く → 売買・交換を縮小し、記録・入荷情報を中心にする |

### いつでも適用する停止条件
- セキュリティ:非公開の情報が他人に見えてしまう不具合、個人情報の漏えいが起きたら、新機能の公開を止めて対応を最優先(個人情報保護委員会への報告が必要な場合がある)。原因と再発防止が済むまで次のフェーズに進まない。
- 作業時間:4週続けて週7時間を大きく超える、または作業の遅れで判定点が2か月以上ずれる → 作る範囲を削る(フェーズ1は成長記録と撮影だけにする等)。
- 運営の手間:通報対応・問い合わせ・イベント情報の登録が週2時間を超える状態が続く → 自動化・主催者による登録・機能の縮小を先に行う。
- 本業との関係:勤務先の副業規定に反する、または本業に支障が出る場合は、指標に関係なく止める。
