# 植物アプリ 市場規模(TAM/SAM/SOM)と5年の収益見通し(2026-09-25 再計算:対象「ハマっている層」)

前提:サービスコンセプトは「植物アプリ_コンセプト」の現行版のまま(記録/来歴、記録閲覧、入荷情報、イベント、相談Q&A、売買・交換。売買・交換は記録公開者のみ)。対象を「ハマっている層」に変更したことに合わせて再計算。1年目は副業(週3〜7時間)、2年目以降は専業の想定(ただし専業化は判断基準を満たした場合のみ)。
※2026-09-26 注記:対象が「初心者から少し踏み込んだ層以上(年齢層は特定しない)」に広がり、取引はアプリ外で成立することがある(手数料はアプリ内で成立した分だけ)前提に決まった。以下の計算は、まだこの前提に直していない(再計算は `decisions.md` の未決事項)。手数料の項は、下の「取れない場合」の値(ARPU 約320円)を下限として見る。
※数値は公開統計と仮定を組み合わせた推計。仮定は明示し、検証で更新する。

## 0. 前回の計算からの訂正(重要)
- 前回(初心者向け)の計算では、広告による1人あたり年間売上を「約110円」としていたが、計算の誤り。月間利用者のうち毎日使う人25%・1日5表示・eCPM 50円の場合、正しくは 0.25×5×365日×0.05円 ≒ 年約23円。
- このため、前回の売上見通し(5年目 基本シナリオ 約3,600万円など)は、広告の分だけ過大だった。今回の計算では訂正済み。
- なお「広告だけで年20万円に必要な規模(毎日使う人 約2,200人)」の試算は正しい。

## 2. TAM / SAM / SOM
### TAM(日本のハマっている層)
- 定義:植物に関心があり、自宅で11鉢以上を育てている人。
- 1.1億人 × 14% × 19% ≒ 約290万人。うち多肉・塊根植物を持つ「レア植物寄り」の中心層 ≒ 約110万人。
- 金額:290万人 × 年410円(成熟時のARPU、下記) ≒ 約12億円/年。
- 注意:インターネット調査のため、関心の高い人が多めに出ている可能性がある。

### SAM(スマホ・SNSで情報収集や交流をしている人)
- ハマっている層はX・Instagram・イベントで活発に動くため、アプリやSNSを使う人を6割と仮定。
| 時期 | 対象地域 | SAM(人) | SAM(金額、年410円換算) |
|---|---|---|---|
| 1〜2年目 | 関東・関西 | 約93万人 | 約3.8億円/年 |
| 3〜5年目 | 全国 | 約176万人 | 約7.2億円/年 |
- 初心者向け(関東関西253万人・全国478万人)より対象は約4割に縮む。その代わり、1人あたりの支出と熱量が高い。

## 3. 1人あたり年間売上(ARPU)の仮定(成熟時、月間利用者1人あたり)
| 収益源 | 仮定 | 年間 |
|---|---|---|
| 広告 | 毎日使う人35%(入荷情報で毎日開く)、1日6表示、eCPM 50円 | 約38円 |
| 有料プラン | 月480円(入荷通知の拡大・即時通知、広告非表示、登録無制限、高画質、同居人共有等)、ストア手数料15%後、加入率4% | 約196円 |
| 売買手数料 | 利用者の15%が年3回販売、平均4,000円、手数料5% | 約90円 |
| 出品オプション | 利用者の10%が年2回、1回200円 | 約40円 |
| 法人(店舗の入荷情報・店舗ページ、イベント掲載) | 月間利用者1,000人あたり月3,000円の店舗を1件 | 約36円 |
| 送客(アフィリエイト) | 資材・用土など | 約10円 |
| 合計 | — | 約410円 |
- 初心者向けとの違い:広告の比重が小さく、有料プラン(入荷通知)と取引(手数料・出品オプション)が柱。
- 年ごとのARPU(機能がそろう段階に合わせる):1年目60円(広告+一部の有料)→ 2年目200円(入荷通知・出品オプション)→ 3年目320円(取引が本格化)→ 4年目380円 → 5年目410円。

### 年間売上(月間利用者 × その年のARPU)
| 年 | ARPU | 保守 | 基本 | 楽観 |
|---|---|---|---|---|
| 1年目 | 60円 | 約3万円 | 約6万円 | 約18万円 |
| 2年目 | 200円 | 約50万円 | 約120万円 | 約400万円 |
| 3年目 | 320円 | 約190万円 | 約580万円 | 約1,900万円 |
| 4年目 | 380円 | 約420万円 | 約1,330万円 | 約4,560万円 |
| 5年目 | 410円 | 約700万円 | 約2,130万円 | 約7,130万円 |
- 費用:サーバー(写真の保存が大きい)・AI・天気データ・決済代行などで売上の約10〜20%、Apple年$99等。専業の場合は自分の生活費が必要。
- 取引の売上には、決済代行サービスを使った手数料の仕組みと法務確認(資金決済法等)が前提。これができないと、手数料分(ARPUの約2割)がなくなる。

## 5. 収益化は可能か(評価)
### 結論
- 収益化は可能。ただし「広告で稼ぐアプリ」ではなく、「入荷通知の有料プラン」と「信頼できる取引(手数料・出品オプション)」で稼ぐアプリになる。
- 1年目に年20万円:難しい(約5%)。1年目は取引・入荷通知がそろわずARPUが低いため、月間利用者 約3,800人が必要(楽観シナリオ以上)。
- 2年目に年20万円:現実的な目標(約30%)。ARPU 200円なら月間利用者 約1,200人で届く(保守と基本の間)。
- 専業で生活できる水準(年間利益300〜500万円):基本シナリオの3年目(売上約580万円)前後。確率は約10〜15%。

### 確率(推測)
| 到達点 | 確率(推測) |
|---|---|
| 1年目に年20万円の利益 | 約5% |
| 2年目までに年20万円の利益 | 約30% |
| 保守シナリオ以上(5年目に売上約700万円) | 約30% |
| 基本シナリオ以上(5年目に売上約2,100万円) | 約10〜15% |
| 楽観シナリオ(5年目に売上約7,100万円) | 数% |
| 保守シナリオにも届かない | 約70% |

### 初心者向けと比べて
| 観点 | 初心者向け | ハマっている層向け |
|---|---|---|
| 対象の人数(SAM全国) | 約478万人 | 約176万人(約4割) |
| 1人あたり売上(成熟時) | 約300円(広告を訂正すると約210円) | 約410円 |
| 収益の柱 | 広告 | 有料プラン(入荷通知)+取引 |
| 毎日開く理由 | 弱い(撮影・水やり) | 強い(入荷情報) |
| 困りごとの強さ | 弱い(土・鉢の余り) | 強い(詐欺・偽物、情報の分散) |
| 立ち上げの集客 | 広く薄い | イベント・Xで集中して届けやすい |
| 運営の負担 | 中 | 大(詐欺・盗難・違法株への対応、議論の荒れ) |
- 総合すると、ハマっている層の方が「収益化の確からしさ」は高い。売上の天井は低くなるが、ARPUが高く、困りごとが強いため。

### 収益化を左右する条件
1. 有料プランの加入率(4%想定):入荷通知に月480円を払うか。→ フェーズ2a+でテスター・初期ユーザーに価格を提示して確認。
2. 取引の手数料を取れる仕組み:決済代行サービスと法務確認。取れない場合、ARPUは約320円に下がる。
3. 入荷情報の掲載量:載る情報が少なければ毎日開く理由が成り立たない。→ 初期は生成AIで公開ページから確度の高い情報を集めて無料で載せ(2026-09-26 決定)、自分で確認する。イベント・店を回って直接確かめる。店舗の公式アカウントは、店の関心を確認してから(後回し)。
4. 信頼の維持:詐欺・盗品・違法株が1件でも広まると、取引の場としての価値が崩れる。→ 来歴記録、通報、セキュリティ要件。
5. ブームの変動:アガベのように価格が大きく下がるジャンルがある。→ 複数ジャンルを横断。

## 6. 専業に切り替える判断基準(推奨)
1年経ったら自動的に専業にするのではなく、次の条件を満たした場合に切り替えることを推奨。
| 指標 | 目安(仮) |
|---|---|
| 月間利用者 | 5,000人以上(基本シナリオの2年目に近い水準) |
| 30日後も使う人の割合 | 15%以上(ライフスタイル系の中央値 約9%を上回る) |
| 月間利用者の伸び | 直近3か月で毎月10〜15%以上 |
| 記録の公開率 | 30%以上 |
| 広告以外の売上 | 有料プラン・出品オプションで月数万円が発生 |
| 生活費の備え | 専業の期間の生活費1〜2年分 |
- 満たさない場合は副業を続けながら改善、または方針の見直し。途中の判定点(4・8・11・12・18か月目)は「植物アプリ_総合評価_2026-09」5章を参照。
- 集客を加速するなら、資金(自己資金・補助金・出資)と、マーケティング・運営を担う仲間の検討が必要。
